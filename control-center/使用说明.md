# OAS 控制中心使用说明

## 程序链路

控制中心分为三层：OAS Core 负责真正执行任务，Bridge 负责把 Core 接口整理成稳定契约，React/Vite 前端负责界面。桌面版只是用 Electron 包住同一份前端，并内置 Bridge。

| 组件 | 默认地址 | 作用 |
|---|---:|---|
| OAS Core | `127.0.0.1:22267` | 控制模拟器、账号和任务 |
| Bridge | `127.0.0.1:22367` | 适配 Core、维护界面元数据 |
| 前端 | 首选 `127.0.0.1:4175` | 浏览器开发和日常操作界面；被 Windows 预留时自动顺延 |

## 日常启动

双击 `D:\OSAyys\启动.bat`。启动器按 Core → Bridge → 前端处理，已经正常运行的服务会直接复用。

PowerShell 等价命令：

```powershell
Set-Location D:\OSAyys
.\control-center\start.ps1
```

可选参数：`-SkipCore` 跳过 Core、`-NoBrowser` 不自动打开浏览器、`-CoreUrl` 指定其他 Core 地址、`-RestartCore` 重启 Core、`-RestartAll` 重启三层。

## 调界面但不碰游戏

```powershell
Set-Location D:\OSAyys
.\control-center\launcher\start-dev-stack.ps1
```

它使用 mock Core `22268`、隔离 Bridge `22368` 和同一份正式前端。前端首选 `4175`，本机因 Windows 预留 `4112–4211` 会自动使用 `4212`。界面中的账号和运行状态是模拟数据，不会绑定真实窗口或启动任务。

## 桌面版

阶段验收或发布时构建：

```powershell
Set-Location D:\OSAyys\control-center\desktop
.\build.ps1 -SkipNpmInstall
```

产物：`control-center\desktop\release\OAS-Control-Center-0.1.0-portable.exe`。

portable 自带前端和 Bridge，但仍要求 OAS Core 已运行。平时只调整界面时不需要反复打包。

## 基本使用

1. 确认 Core 在线。
2. 在左侧选择正确账号。
3. 在“任务”页点击任务名称查看配置，使用右侧开关启用或停用。
4. 在“运行设置”中给当前账号绑定正确的模拟器、ADB 地址和窗口。
5. 保存改动后回到“概览”检查 Core、设备、任务和实时通道。
6. 点击启动并到“日志”页观察运行情况。

关闭控制中心不等于停止任务。需要停止时，必须在正确账号上点击“停止”。

## 常见检查

```powershell
Invoke-RestMethod http://127.0.0.1:22267/test
Invoke-RestMethod http://127.0.0.1:22367/api/v1/health
Get-NetTCPConnection -State Listen | Where-Object { $_.LocalPort -in 22267,22367,4175 }
.\control-center\check-wiring.ps1
```

不要直接打开 `frontend/dist/index.html` 调试，开发模式必须从 Vite 地址访问。不要通过手改 `config/*.json` 绕过界面保存错误，应先看 Bridge 返回信息和账号日志。
