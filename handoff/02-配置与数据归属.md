# 配置与数据归属

## 数据所有权

| 数据 | 事实来源 | 允许的写入方 |
|---|---|---|
| 账号配置与任务参数 | OAS Core 的 config | Core 或经过 Bridge 的明确保存操作 |
| 任务执行与调度状态 | Core、账号运行时和 checkpoint | Core |
| 账号昵称、标签、排序 | Bridge SQLite | Bridge |
| 前端实际端口 | output/control-center/frontend.json | 启动脚本 |
| 前端临时模板和布局 | 浏览器 localStorage 或前端运行目录 | 前端 |
| Core 详细日志 | D:\OSAyys\log | Core |
| 实测截图和证据 | handoff 记录或指定 evidence 目录 | 实测记录 |
| 坐标校准会话 | D:\coordinate-calibrator\data | 独立坐标工具 |
| 坐标候选导出 | D:\coordinate-calibrator\outputs | 独立坐标工具，人工确认后使用 |

## 边界

- 前端不得直接读取或写入 config\*.json。
- Bridge 不复制 Core 任务逻辑，只做适配、状态和界面元数据。
- 坐标校准工具不得写入 OAS 的 tasks、assets.py、config 或正式日志。
- 任何候选规则都必须先生成预览、来源哈希和转换警告，再由人工决定是否应用。
- 账号、设备序列号、窗口句柄和日志路径属于运行数据，不应写进可发布示例配置。

## 备份要求

修改业务配置前保存配置快照和文件哈希。修改任务代码前记录文件、根因、测试结果和回滚点。不得用临时导出文件覆盖正式配置。
