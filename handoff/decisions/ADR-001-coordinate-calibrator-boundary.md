# ADR-001 通用坐标校准工具与 OAS 的边界

日期：2026-08-07

## 决策

坐标校准工具作为独立项目 D:\coordinate-calibrator 维护。OAS/MuMu 是第一套适配器和验收环境，不把工具核心放进 OAS module 或 tasks。

工具默认只做窗口绑定、截图、鼠标点击采集、标注、统计、回放和候选导出。v1 不自动点击，不启动或停止进程，不修改 OAS 配置、任务、资源或日志。

## 原因

OAS 当前标注器依赖 Core 配置和任务资源，保存流程会生成业务资产。通用工具如果直接复用写入路径，采集阶段就可能误改正式配置。独立边界可以保留 OAS 适配能力，同时让几何、统计和坐标换算不依赖游戏项目。

## 结果

- OAS 只提供只读截图/设备适配和候选格式预览。
- 候选文件包含源截图/报告 SHA-256、置信度和转换损失。
- 未来如果需要自动应用，必须另立版本，增加预览、备份、文件锁、哈希校验和人工确认。
