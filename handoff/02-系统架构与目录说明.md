## 职责边界

### 前端

前端只依赖 `/api/v1`，不读取 OAS JSON，不导入 OAS Python 包，不依赖 OAS 内部类名。它负责界面状态、中文显示、本地模板和显示排序。

### Bridge

Bridge 把 OAS 的任务菜单、参数 Schema、状态和 WebSocket 消息转换成相对稳定的控制中心契约。它还负责每个账号的运行时对象和 UI 元数据数据库。

### OAS Core

Core 是唯一的任务配置和执行事实来源。实际配置保存、任务调度、设备操作和任务执行仍由 Core 完成。

## 数据归属

| 数据 | 来源/存储 | 是否由前端直接修改 |
|---|---|---|
| 账号配置文件 | OAS `config/`，由 Core 管理 | 否，通过 Bridge 调 Core |
| 任务参数 | OAS Core Schema 和配置 | 否，通过 Bridge 调 Core |
| 账号昵称、头像、标签、设备显示名、排序 | Bridge SQLite `control_center.db` | 是，通过 Bridge |
| 任务显示排序 | 浏览器/Electron localStorage | 是 |
| 配置模板 | 浏览器/Electron localStorage | 是 |
| 实时状态、日志缓存 | Bridge 进程内存，最多保留 300 条 | 否，重启 Bridge 后清空内存日志 |
