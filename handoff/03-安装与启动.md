# 03 安装与启动

## 已验证环境

交接快照使用：

- Windows 10/11；
- Python 3.11.15；
- Node.js v22.23.1；
- npm 10.9.8；
- OAS Core `127.0.0.1:22267`；
- Bridge `127.0.0.1:22367`；
- Vite `127.0.0.1:5173`。

OAS 原项目 README 标注的开发版本为 Python 3.10；实际接手时以原项目依赖兼容性为准。控制中心的 Bridge 已在 Python 3.11.15 下验证。

## 第一次安装

在 PowerShell 中：

```powershell
Set-Location D:\OSAyys

# 原项目依赖按原项目说明安装；如果项目已有 .venv，不要重复创建
.\.venv\Scripts\python.exe -m pip install -r .\requirements.txt

# Bridge 依赖
.\.venv\Scripts\python.exe -m pip install -r .\control-center\bridge\requirements.txt

# 前端依赖
npm --prefix .\control-center\frontend install

# Electron 打包依赖
npm --prefix .\control-center\desktop install

# 只有需要重新打包桌面版时才需要 PyInstaller；可安装到用于打包的 Python
python -m pip install pyinstaller
```

当前 `start-bridge.ps1` 会优先寻找项目根目录 `.venv`，然后寻找 `control-center\bridge\.venv`，最后使用 PATH 中的 `python`。桌面构建脚本会从这些 Python 中选择带 PyInstaller 的解释器。

## 启动 OAS Core

如果 Core 尚未运行，可以按原项目方式启动。当前配置默认监听 `127.0.0.1:22267`：

```powershell
Set-Location D:\OSAyys
.\.venv\Scripts\python.exe server.py --host 127.0.0.1 --port 22267
```

如果已经有原项目 GUI、服务管理器或其他启动方式，不要重复启动第二个 Core。确认方式：

```powershell
Invoke-RestMethod http://127.0.0.1:22267/test
# 预期：success
```

## 开发模式启动

推荐一次启动 Bridge 和前端：

```powershell
Set-Location D:\OSAyys
.\control-center\launcher\start-all.ps1
```

也可以分开启动：

```powershell
.\control-center\launcher\start-bridge.ps1
.\control-center\launcher\start-frontend.ps1
```

打开：`http://127.0.0.1:5173`

如果 Core 不是默认端口：

```powershell
.\control-center\launcher\start-bridge.ps1 -CoreUrl http://127.0.0.1:22270
```

前端开发服务器通过 Vite proxy 把 `/api` 和 WebSocket 转发到 Bridge。

## 桌面版构建

```powershell
Set-Location D:\OSAyys\control-center\desktop
.\build.ps1
```

若 npm 依赖已经安装，可省略安装步骤：

```powershell
.\build.ps1 -SkipNpmInstall
```

只改前端、不改 Bridge 时：

```powershell
.\build.ps1 -SkipNpmInstall -SkipBridge
```

输出：

```text
D:\OSAyys\control-center\desktop\release\OAS-Control-Center-0.1.0-portable.exe
```

桌面版不需要 Vite 开发服务器，但仍需要 OAS Core。Electron 会在本地启动打包后的 Bridge；如果发现 `22367` 已有 Bridge，则复用现有服务。

## 停止

停止开发模式的 Bridge/Vite 窗口即可。控制中心不会替用户关闭 OAS Core。停止任务应在选中正确账号后使用界面中的“停止”按钮，不能把关闭控制中心误认为停止自动化任务。
