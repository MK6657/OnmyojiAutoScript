## 三、新发现（独立于审计）

### CC-ENV-001【P2】netstat 输出解码无防护（一行级修复）
- 位置：`adapters/capture/common.py:140-165` `_local_endpoint_pid` 的 `subprocess.run(['netstat','-ano','-p','tcp'], capture_output=True, text=True)`
- 触发：**UTF-8 locale**（如 Hermes shell 的 PYTHONUTF8=1）下，中文 Windows netstat 输出 GBK → `UnicodeDecodeError: 'utf-8' codec can't decode byte 0xbb` → reader 线程崩 → **stdout=None** → `result.stdout.splitlines()` AttributeError（父代理两次完整复现：stdout=None + rc=0 证据链）
- 影响：`local_emulator_identity_provider` → Nemu 帧源身份基线获取失败；0.3.7 新增 2 个 Nemu 挂起测试在 UTF-8 locale 失败（**实际测试数 145 非审计的 126**）
- 环境确认：`PYTHONUTF8=0`（cp936 locale）+ discover 方式 → **14/14 全过**（父代理复验）——纯环境相关；PowerShell 生产启动（start.ps1）走系统 locale 大概率 cp936 不触发，但任何 UTF-8 shell 启动即触发
- 修复：`text=True, encoding='gbk', errors='replace'`（或统一 errors='replace'）——防御任何 locale
- 离线用例：UTF-8 环境跑 test_capture_sources 断言通过；模拟 netstat 非 UTF-8 输出断言不崩
