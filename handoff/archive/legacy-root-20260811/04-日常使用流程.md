# 04 日常使用流程

## 推荐流程

1. 启动 OAS Core；
2. 启动控制中心或打开 portable 程序；
3. 确认左侧显示“Core 在线”；
4. 在账号列表选择要操作的账号；
5. 在左侧“全部任务”点击任务名称，查看它的配置；
6. 需要加入调度时，点击该任务右侧的 `＋`；
7. 已启用任务会出现在“当前账号任务”列表；
8. 需要调整执行顺序时，用任务右侧的上移/下移按钮；
9. 在“任务设置”中修改参数，点击“保存”；
10. 检查设备、账号、调度和任务参数无误后，再点击顶部“启动”。

## 任务目录和当前任务的区别

- “全部任务”是 Core 返回的完整目录，共 53 项；点击名称只切换配置预览；
- `＋` 才是启用/加入当前账号调度；
- “当前账号任务”只显示当前账号已启用的任务；
- 当前账号任务的 `×` 是停用，不会删除任务代码；
- “独立配置”表示配置保存到当前账号对应的 OAS 配置文件。

## 配置模板

模板是前端本地模板，不会自动同步到 Core：

1. 选中一个任务；
2. 调整表单内容；
3. 输入模板名称，点击“保存模板”；
4. 切换到另一个账号的同名任务；
5. 在模板下拉框选择模板；
6. 点击“应用”；
7. 检查表单后点击“保存”，才会写入另一个账号的 Core 配置。

删除模板只删除本地模板，不会删除 Core 任务或账号。

## 启动前检查

- 设备序列号或窗口句柄是否正确；
- 游戏客户端和截图/控制方式是否匹配；
- 任务是否已启用；
- 下一次运行时间、间隔和优先级是否符合预期；
- 当前选中的账号是否正确；
- 日志中是否出现连接或配置错误。

## 日志

日志面板只显示关键日志和运行状态。Bridge 运行时最多缓存每个账号最近 300 条日志，前端默认拉取最近 120 条。完整错误截图和 Core 详细日志仍在原 OAS 的 `log/` 目录中查找。
