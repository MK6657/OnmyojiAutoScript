## 3. 已发现的基础问题

### 3.1 启动自检脚本编码

`check-wiring.ps1` 与 `launcher/start-all.ps1` 原文件没有 UTF-8 BOM。Windows PowerShell 按系统代码页读取中文 UTF-8 文件时，会把后续字符串解析错，导致自检脚本在服务启动前直接语法失败。该问题与 Core、Bridge 是否在线无关。

本轮处理：

- `check-wiring.ps1` 的 URL 插值改为显式 `${CoreUrl}` / `${BridgeUrl}` 边界。
- 相关 PowerShell 文件随后统一转为 Windows PowerShell 可识别的 UTF-8 BOM。

### 3.2 GeneralBattle 测试夹具

生产代码的 `is_in_real_battle()` 会调用 `ocr_appear()`，两个测试夹具没有提供该方法，造成 2 个测试夹具错误。本轮补充始终返回 `False` 的测试桩，不改变生产逻辑。

### 3.3 Bridge 测试输出编码

Bridge 自定义回归测试逻辑本身可通过，但默认中文控制台无法输出 `✓`，导致测试在汇总输出阶段抛出 `UnicodeEncodeError`。本轮让测试脚本显式使用 UTF-8 输出。
