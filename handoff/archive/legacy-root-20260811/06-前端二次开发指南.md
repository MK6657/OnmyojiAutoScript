# 06 前端二次开发指南

## 唯一源码

所有界面开发只修改：

```text
D:\OSAyys\control-center\frontend
```

浏览器、隔离联调、Electron 和 portable 都从这里构建。不要在 `desktop/ui`、`desktop/release` 或其他预览目录直接改界面。

## 开发命令

```powershell
Set-Location D:\OSAyys\control-center\frontend
npm install
npm run dev -- --host 127.0.0.1 --port 4175
npm run build
npm run build:desktop
```

日常更推荐从根目录运行 `control-center/start.ps1`，它会正确连接真实 Bridge。无游戏联调使用 `control-center/launcher/start-dev-stack.ps1`。

## 代码分工

- `src/App.jsx`：应用外壳、账号与全局状态。
- `src/api.js`：Bridge REST 和 WebSocket 客户端。
- `src/views.jsx`：概览、任务、日志和设置视图。
- `src/fields.jsx`：配置字段编辑器。
- `src/components.jsx`：通用组件。
- `src/store.js`：主题、密度与本地降级存储。
- `src/locale.js`：任务、字段和枚举中文映射。
- `src/styles.css`：布局、主题和字体样式。
- `tools/`：隔离 mock 与端到端验证。

## 数据边界

前端只能调用 Bridge 的 `/api/v1` 和事件 WebSocket。不要直接读取或写入 `config/*.json`，不要复制 Python 任务逻辑到前端，也不要在没有明确账号的情况下发送启动、停止或删除动作。

## 桌面验收

平时样式调整使用 Vite 热更新。阶段验收时运行：

```powershell
Set-Location D:\OSAyys\control-center\desktop
.\build.ps1 -SkipNpmInstall -SkipBridge
```

确认 `file://` 下的 API 回退、DPI/缩放、窗口最小尺寸和 Bridge 连接正常后，再执行完整 portable 构建。
