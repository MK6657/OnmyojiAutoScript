# Codex-54 寮突破最高勋章自动选寮实施记录

日期：2026-08-07
分支：`codex/mk6657-secondary-development`

## 1. 需求

当进入寮突破页面但没有选择目标寮时，不依赖寮名称，使用游戏页面的“勋章奖励”排序能力，自动选择勋章数量最高的寮：

`选择阴阳寮` -> `勋章奖励`降序排序 -> 排序后的第一张寮卡 -> `突入开始` -> 确认回到寮突破棋盘。

截图中的“青灯不归客”仅作为当次示例名称，不参与代码判断。

## 2. 实现

- `tasks/RyouToppa/assets.py` 新增 `C_GUILD_ORDERS_REWARDS`，用于点击勋章奖励排序按钮。
- `tasks/RyouToppa/script_task.py` 的入口状态在检测到未选寮时，调用 `_auto_select_highest_medal_ryou()`。
- 选择流程先打开选择面板，再点击游戏原生的勋章奖励排序按钮；排序完成后只点击第一张寮卡，不读取或匹配寮名称。
- 点击寮卡后等待 `I_START_TOPPA_BUTTON`，点击突入开始；随后必须看到棋盘、寮奖励、成功标记之一，才把入口判定为成功。
- 排序按钮、第一张寮卡、突入开始或棋盘确认任一步超时，返回 `guild_auto_select_failed`，不擅自选择其他寮、不进入战斗。
- 已选寮的原有流程不变；个人突破、困28、持久配置和战斗失败策略不变。

## 3. 离线验证

`tasks/RyouToppa/tests/test_ryou_flow.py` 增加自动选寮测试，覆盖：

- 排序点击发生在第一张寮卡点击之前。
- 点击排序后的第一张寮卡后会点击突入开始。
- 只有看到棋盘标记才报告入口成功。

2026-08-07 验证结果：寮突破定向单测 `6` 项全部通过；目标文件 `py_compile` 通过；`git diff --check` 通过。
