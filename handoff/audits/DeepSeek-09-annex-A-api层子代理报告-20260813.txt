## ② 新发现问题清单

- **N1 🟡 注意｜bundle 导入阻塞事件循环**（app.py:1468-1497 + bundles.py:447）。现象：128MB ZIP 解压+哈希+图像校验+逐画布 DB/FS 写入全部在事件循环线程同步执行，期间 health/WebSocket 全部等待。置信度=已证实（代码事实；阻塞时长未实机测量）。即清单#4，audit P2 未修。
- **N2 🟡 注意｜幂等 owner 维度 DB 层失效**（repository.py:373-376 vs 675）。begin 查询用 `WHERE route=? AND idempotency_key=?`（不带 owner），而表约束是 `UNIQUE(route, owner, idempotency_key)`，且指纹不含 owner → 跨 owner 同 key 同 body 会命中他人记录并回放其响应（内存注册表按 owner 分键，重启后 DB 层暴露）。置信度=已证实。
- **N3 🟡 注意｜lease/acquire 幂等重放可返回已失效租约**（idempotency.py:133-139；app.py:840-844）。acquire 无 lease_session_id → 指纹不含租约；同 key 重试在 TTL 内直接返回缓存 envelope（含旧 lease_id），不重新校验该租约是否仍有效；客户端拿到死租约后首个操作 423 自愈。与协议"identical replay returns the committed result"字面一致，但属 P2 同族残留。置信度=已证实（代码路径）。
- **N4 🟡 注意｜Session 序列化无锁读**（runtime.py:123-161；app.py:879-880,1199）。`as_dict()` 直接迭代 annotations/samples/backgrounds dict，GET 路径不持 `_session_lock`；与写线程并发时理论上可抛 "dictionary changed size during iteration"→500。audit P2 该条仍存在。置信度=已证实（代码事实，触发概率低）。
- **N5 🟡 注意｜隔离区无配额上限**（runtime.py:541-569,1836-2102；repository.py:2880-2896）。quarantine 写入不经过任何 max_files/max_bytes 统计（quota 只统计 artifacts 表 staging/ready 行），永久删除画布可无限堆积文件。audit P2 该条仍存在。置信度=已证实。
