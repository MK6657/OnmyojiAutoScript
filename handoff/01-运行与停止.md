# 运行与停止

## 真实环境

日常真实环境的主入口是：

~~~powershell
Set-Location D:\OSAyys
.\control-center\start.ps1
~~~

启动顺序为 Core -> Bridge -> 前端。脚本会复用已经健康的本项目服务，Core 不应重复启动。前端首选 4175，若端口被占用或被系统保留，会顺延到空闲端口；实际地址读取 output\control-center\frontend.json 或启动器输出。

control-center\launcher\start-all.ps1 是兼容包装器，默认转发到 start.ps1 -SkipCore，不作为新的独立启动链。

## 隔离联调

无游戏联调使用：

~~~powershell
Set-Location D:\OSAyys
.\control-center\launcher\start-dev-stack.ps1
~~~

隔离环境使用 mock Core 22268、测试 Bridge 22368 和独立数据目录。隔离测试禁止指向正式 Bridge 22367 写入真实账号。

## 停止与重启

- 停止任务：在控制中心停止账号任务，只影响任务实例，不等同于关闭服务。
- 关闭服务：按端口、PID 和命令行确认后关闭 Core、Bridge 或前端。
- 重启 Core：修改 Core 代码、设备链路或资源后使用 -RestartCore。
- 全部重启：只有确认没有需要保留的任务状态时使用 -RestartAll。
- 不得根据窗口标题盲杀未知进程；先核对 PID、端口、命令行和启动时间。
- 同一账号、同一设备、同一任务只允许一个实时任务实例。

## 启动前门禁

1. 确认 Core、Bridge、前端是否已经健康运行。
2. 确认目标账号没有运行任务或旧子进程。
3. 确认 MuMu 绑定的是用户指定窗口，例如 2301，而不是枚举结果中的第一项。
4. 确认截图为 1280x720、方向正确，必要时重新校准画布。
5. 确认测试配置快照和 checkpoint 已保存。

## 常见错误

- 页面没有任务：检查 Core health、Bridge 的 core_url 和实际前端 URL。
- 任务重复：先检查同账号子进程和调度快照，再决定是否停止旧实例。
- 点击到模拟器顶部栏：说明游戏画布坐标和窗口坐标混用，应使用坐标校准工具。
