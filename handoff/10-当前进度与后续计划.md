# 10 当前进度与后续计划

## 当前状态

当前版本可作为本地可用的控制中心交付给接手者继续开发。前端、Bridge、桌面版和交接资料均已在本机完成构建或接口回归。

## 已完成

- 前端与 OAS Core 解耦；
- FastAPI Bridge 和事件契约；
- 多账号工作区；
- 每账号独立任务列表、配置、状态和日志；
- 全任务目录 53 项展示；
- 任务点击查看配置、加号启用；
- 启用任务排序和停用；
- 配置保存；
- 配置模板保存、应用、删除；
- 中文任务、分组、字段、说明、选项；
- 内部任务 ID 保留为对照标识；
- 独立滚动和紧凑关键日志；
- Electron portable 桌面版；
- PyInstaller Bridge 健康检查；
- 启动/构建脚本优先使用项目虚拟环境；
- 交接文档和 ZIP 交接包。

## 当前已知限制

1. 桌面版仍需要 OAS Core 作为独立服务；
2. 当前控制中心没有账号权限系统，只适合本机使用；
3. 任务显示排序和模板存于浏览器/Electron 本地存储，尚未进入 Bridge 数据库；
4. Bridge 的运行日志缓存在内存，重启后需要重新产生；
5. 中文映射需要随着上游新增字段持续补充；
6. 多账号“逻辑隔离”已实现，但真实多窗口并行仍依赖正确的设备/模拟器配置；
7. 本次没有在真实设备上执行任务。

## 建议的后续优先级

### P0：接手后先做

- 用测试账号和测试模拟器验证一条任务完整启动、停止、重启流程；
- 验证两个账号使用两个设备时的并行运行；
- 记录 Core 上游版本和当前配置备份。

### P1：增强可靠性

- 为 Bridge 增加接口级自动化测试和模拟 Core 测试桩；
- 将模板和任务排序从 localStorage 迁移为可备份的 Bridge 数据；
- 增加桌面版 Core 地址配置入口；
- 增加启动前设备和任务配置校验。

### P2：体验提升

- 增加账号标签编辑、头像颜色和设备显示名编辑界面；
- 增加任务配置变更摘要和未保存提示；
- 增加日志级别筛选和导出；
- 增加上游任务差异扫描工具，自动提示新字段。
