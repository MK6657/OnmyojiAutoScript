## 2. 庭院 → 探索：整条玩法链路的真正卡点

### 现象
`WARNING | Failed recognize PAGE_MAIN_GOTO_EXPLORATION on page_main` 无限重复，
账号停在庭院进不了探索，**后面所有玩法（结界突破/御魂/觉醒/探索…）全部接不上**。

### 排除误解：不是窗口缩小
OAS 走 **MuMu IPC 直接抓模拟器显存**，与 Windows 窗口大小无关。
证据：OAS 自己保存的错误截图是**标准 1280×720、画面完整清晰**。

### 量化根因
用错误截图做模板匹配（搜索区 roi_back = 243,100,933,211）：

| 场景 | 最佳匹配分 | 位置 |
|---|---|---|
| 白天皮肤 | ≈1.0 | — |
| **夜间/樱花活动皮肤** | **0.561** | (654,148) 正确位置 |
| 画面中没有该按钮（噪声上限） | 0.363 | — |
| 原阈值 | **0.8** | → 夜间必然失配 |

**庭院会随时间/活动换皮**，「探索」灯笼的配色、亮度整体改变，单张白天模板必然失配。

### 为什么不用「降阈值」
降到 0.5 虽然能过，但离噪声上限 0.363 只有 0.14，且夜间分 0.561 距 0.5 仅 0.06 —
弹窗遮挡或换个活动就会再次失败。**治标不治本**。

## 3. 解法：给识别层加「多模板」通用能力

### 改动 1 · `module/atom/image.py`（通用，惠及所有资源）
`RuleImage.file` 支持用 **`|`** 分隔多张模板，匹配时逐张计算、**取最高分**：

- `__init__`：解析 `self.files`，`self.file` 仍为首张（`name` 等行为不变）
- `load_image()`：加载全部到 `self._images`（顺带兼容带 alpha 通道的 PNG）
- `match()`：遍历所有模板取最高分；命中后把 `roi_front` 的宽高同步为命中模板的尺寸，
  保证 `coord()` / `front_center()` 点在正确位置；模板比搜索区大时跳过（避免 matchTemplate 抛异常）

**完全向后兼容**：不含 `|` 的老写法行为与原来完全一致。

### 改动 2 · `tasks/GameUi/assets.py`
```
I_MAIN_GOTO_EXPLORATION: threshold 保持 0.8
file = "page_main_goto_exploration.png|page_main_goto_exploration_night.png"
```

### 改动 3 · 新增 `tasks/GameUi/page/page_main_goto_exploration_night.png`
从 OAS 自己的 1280×720 错误截图中按 (654,148,45,75) 裁出的夜间版灯笼。

### 实测效果（阈值 0.8）

| 场景 | 最高分 | 判定 |
|---|---|---|
| 夜间庭院 | **1.000**（夜间模板） | 命中，位置 (654,148) 正确 |
| 白天庭院 | ≈1.0（白天模板） | 命中 |
| 非庭院界面 | 0.363 | 不误报 |

**安全间隔从 0.06 提升到 0.64**，且以后遇到新皮肤只需再截一张图加进 `file`，不用改代码。

## 5. 方法论沉淀（给后续逐个玩法打通用）

一路排查下来，OAS 的失败模式高度同质，就三条：

1. **`while 1` + 图像识别 + 无超时** → 认不出就静默死循环（handoff/20、21 各一例）
2. **模板对皮肤 / 版本 / 活动敏感** → 一变就废（本篇）
3. **循环体内不打日志** → 用户完全看不出卡在哪

对应的通用对策（已具备前两项能力）：

| 病 | 对策 | 状态 |
|---|---|---|
| 死循环 | 所有等待限时 + 超时打明确日志 + 降级继续 | 已在 RealmRaid / GeneralBattle 落地，可推广 |
| 模板脆 | **多模板**（`file` 用 `\|` 分隔） | ✅ 本篇实现，全局可用 |
| 看不见 | 失败时打印「在等什么 + 匹配分」 | 部分落地（`debug_mode` 会打分） |
| 认不出但知道位置 | 按 ROI 中心坐标兜底点击 | 已在退出战斗流程落地 |

**接入新玩法的标准流程**：
跑一次 → 看日志卡在哪个资源 → 用 OAS 自己存的错误截图（`log/error/*/`）做模板匹配算分 →
分低就补一张模板；会死循环就加超时兜底 → 复跑验证。
