# 跨项目中立证据契约 v1 实施记录

日期：2026-08-09

## 结论

OAS 与 coordinate-calibrator 之间已建立只读、中立、可版本化的证据契约。契约只描述身份、帧、候选和证据，不提供自动写回 OAS 的能力。

## 交付

- `handoff/contracts/v1/contracts.schema.json`：JSON Schema Draft 2020-12。
- `handoff/contracts/v1/examples.json`：五类对象的示例。
- `handoff/contracts/v1/README.md`：边界、版本和校验规则。
- `module/server/tests/test_neutral_contracts.py`：零第三方依赖的契约回归。

对象包括：

- `DeviceIdentity`
- `FrameEnvelope`
- `CandidateEnvelope`
- `EvidenceManifest`
- `BattlePreparationResult`

## 固定边界

- 证据文件使用 `artifact://` 引用，不携带本机绝对路径。
- HWND 以字符串传递，避免跨语言整数精度问题。
- ADB serial 别名只能作为 alias，不能单独证明稳定设备身份。
- 候选固定为 `candidate_only`；应用前必须另行验证、预览、备份、加锁和人工确认。
- coordinate-calibrator 不写入 OAS 的 `tasks`、`assets.py`、`config` 或日志。

## 验证

- 契约专项：`3/3`。
- 契约测试已计入 OAS 本轮 `317/317`。
- 运行时自动消费这些契约尚未实现；文档和 Schema 的存在不等于两个项目已自动互通。
