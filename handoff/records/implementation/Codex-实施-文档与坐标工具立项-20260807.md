# Codex 实施记录：文档与通用坐标校准工具

日期：2026-08-07

## 范围

本轮补齐 OAS 当前事实源，并在 D:\coordinate-calibrator 建立独立坐标校准工具 v0.1 的可运行 MVP。没有修改 OAS 任务、设备、资源或业务配置代码。

## OAS 文档变更

- 新增当前状态、运行停止、配置归属、任务生命周期和测试结案规范。
- 新增 RR-COMBAT-001、EXP-028、RY-GUILD-001、COMBAT-PREP-001 当前规格页。

- 当前快照记录 Core 22267、Bridge 22367、前端 4175、oas1 offline、窗口 2301 和未建立画布映射。

## 独立工具变更

- 创建 Python 3.11、FastAPI、原生 HTML/JavaScript 的本地项目骨架。
- 实现 screen/canvas 坐标转换、动态映射版本、画布外拒绝。
- 实现 point、rect、circle、ellipse、polygon 验证和关系计算。
- 实现中位数、MAD、P05/P95、异常值和推荐 ROI 报告。
- 实现 SQLite 会话元数据和独立截图/导出目录。
- 实现 Windows 窗口枚举、ClientRect 画布候选和动态屏幕矩形。
- 实现 Windows 低级鼠标钩子及轮询兜底，默认只监听左键。
- 实现 FastAPI REST、WebSocket、同源本地令牌和基础浏览器界面。
- 实现 OAS 候选导出；不提供 OAS 自动写回。
- 实现 OAS 只读环境描述和安全相对路径读取。
- 实现按日期的本地结构化日志，不记录令牌或完整屏幕内容。
