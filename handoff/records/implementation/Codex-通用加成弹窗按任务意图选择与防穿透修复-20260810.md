# 通用加成弹窗按任务意图选择与防穿透修复

实施时间：2026-08-10

状态：代码与离线回归完成；取消分支的修复后真实复测待下一次弹窗出现。

## 目标

“15 分钟未使用加成”弹窗不再固定点击确认，而是按当前任务真实配置选择动作：

- 当前任务显式启用了受支持的加成时点击“确认”，继续开启对应加成。
- 当前任务没有启用受支持的加成、没有可识别的加成配置或任务未注册时点击“取消”，保持加成关闭。
- 未知任务默认取消，避免在没有用户授权的情况下消耗加成时间。

## 配置决策

处理器只读取已经存在的任务配置，不写配置。首批显式映射覆盖：

其中 `sougenbi` 和 `tako` 还要求各自的总开关已启用。任一已注册的目标加成为 `true` 才选择确认；全部为 `false` 时选择取消。`RyouToppa` 当前没有任务级加成控制，按安全默认选择取消。

结构化证据新增 `choice`、`task_name`、`enabled_buff_fields`、`intent_reason` 和实际 `safe_rect`，日志中的 `clicked` 不再等同于弹窗已解决。

## 防点击穿透

首次取消分支真实事件中，弹窗关闭动画仍在进行，分发器在约 `0.56s` 后再次识别到旧弹窗并执行第二次取消点击。第二次点击穿透到弹窗下方的寮突破目标卡片，最终打开“组队/进攻”详情页。

修复后，长时间加成处理器拥有专属 `0.8s` 动作后等待。分发器完成点击后先等待关闭动画，再获取下一张有效帧；好友邀请和其他处理器继续使用原默认轮询间隔。该修复保留总预算、两帧消失确认、设备身份和帧递增约束。
