# 根许可证切换检查表

本检查表用于未来把仓库从当前历史 GPLv3 口径切换到 MK6657 选定的正式许可证。当前尚未执行切换。

## 切换前

- [ ] 确认新许可证的名称、全文、适用主体、允许的内部使用和商业分发范围。
- [ ] 将上游授权原始证据离线归档，并记录它覆盖的代码版本、授权主体和处置范围。
- [ ] 对 `THIRD-PARTY-NOTICES.md` 中全部“待核实”项目完成文件级审计。
- [ ] 对 AzurLaneAutoScript、StarRailCopilot 等第三方 GPL 派生内容确定保留边界、独立授权或重写方案。
- [ ] 为后续贡献确定贡献协议：权利转让、专有许可或贡献者许可协议三选一并形成书面规则。
- [ ] 确定许可证切换生效的 Git 提交和首个发行版本，不追溯改写历史提交。

## 切换提交

- [ ] 用新许可证替换根 `LICENSE`，并保留 `legal/licenses/GPL-3.0-upstream.txt` 作为历史快照。
- [ ] 更新根 `README.md`、项目关于页面、桌面客户端关于窗口和安装包元数据。
- [ ] 生成并随发行物携带第三方通知和许可证原文。
- [ ] 统一新增自有源码的版权头部；历史作者信息通过本目录和 Git 历史继续可追溯。
- [ ] 在发行说明中标出这是 MK6657 负责的二次开发版本及许可证切换的生效版本。
- [ ] 检查源码、构建脚本、包描述、网站和二进制资源中是否仍有互相冲突的许可声明。

## 切换后

- [ ] 从干净检出构建一次正式发行物并核对其中的许可证、署名和第三方通知。
- [ ] 给发布包和更新清单签名，保存提交号、构建来源和文件哈希。
- [ ] 在 CI 中增加许可证扫描、未知依赖阻断和通知文件完整性检查。
- [ ] 后续每次引入上游更新时重新检查该更新的来源与授权，不能默认沿用本次授权结论覆盖新第三方代码。
